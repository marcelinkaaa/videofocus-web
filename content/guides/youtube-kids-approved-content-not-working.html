Short answer Most "not working" reports are the mode doing what it was designed to do. It's set per child profile by a signed-in parent, search is switched off on purpose, and you can only approve what's in the YouTube Kids catalog, so channels outside it can't be added and approved items can disappear when YouTube removes them. If you need channels YouTube Kids doesn't carry, you need a different tool.

The option is missing

  • You're not signed in as a parent. The approved-content setting only appears for profiles created by a signed-in parent Google account. If YouTube Kids is used signed out, the content levels are all you get.
  • You're looking in the wrong place. The setting lives in the parent settings for each child's profile, behind the parent gate, not in the app's general settings.
  • It's set per profile. Each child needs it switched on separately.

Search disappeared

That's by design. In approved-content mode YouTube Kids turns search off for the child, because search would reach beyond your list. Kids see an "Approved for you" home instead. Parents can still search when approving.

A channel I want isn't there

YouTube Kids only carries content it has cleared for the app. Many general-audience channels kids love (science, maker, Minecraft building, educational channels made for all ages) aren't in the catalog, so they can't be approved. This is the most common reason families with kids over about 8 move on. Kids often call YouTube Kids "baby YouTube" for exactly this reason.

Approved videos or channels vanished

  • The creator made the video private or deleted it.
  • YouTube removed it from the YouTube Kids catalog.
  • You approved a single video, not the channel, so new uploads don't appear.

Approving whole channels or collections rather than single videos keeps the library from going stale.

It works on the tablet but not the TV

Approved-content settings belong to the child's profile in the YouTube Kids app. If the TV is signed out, or uses a different profile, it won't follow them. Sign the TV in to the same parent account and pick the same child profile.

My child gets around it

The default parent gate asks a simple question an older child can answer. In the parent settings, set your own custom passcode instead. Also check that the main YouTube app and any browser are blocked on the device with Screen Time, or the allowlist is easy to sidestep.

When it's time to switch

YouTube Kids' approved mode is a good free option for young children whose favorite channels are in its catalog. It stops fitting when:

  • the channels you want aren't in the YouTube Kids catalog;
  • you want approvals to cover a channel's new uploads automatically;
  • you want screen time limits and a bedtime inside the same app.

Questions parents ask

Why is there no "approved content only" option in my YouTube Kids?

The option only appears for child profiles set up by a signed-in parent Google account, and it's set separately for each profile in that child's parent settings.

Can kids search in approved content only mode?

No. Search is turned off for the child in that mode, on purpose. Only the parent can search when approving content.

Can I approve any YouTube channel in YouTube Kids?

No. You can only approve content that's available in the YouTube Kids app. Channels that are only on regular YouTube can't be added.
